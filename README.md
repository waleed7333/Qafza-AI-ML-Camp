## About

This repository documents my practical work throughout the Qafza AI & Machine Learning Camp.

It is organized around the actual assignments delivered during the program, with each assignment maintained as a self-contained project including its own documentation, environment-specific configuration, and implementation files.

The repository is intended to reflect both the technical solutions and the engineering practices developed throughout the program.

## Repository Structure

```text
qafza-ai-ml-camp/
│
├── README.md
├── LICENSE
│
└── assignments/
    │
    ├── 01-<assignment-name>/
    │   ├── README.md
    │   ├── .gitignore
    │   └── ...
    │
    ├── 02-<assignment-name>/
    │   ├── README.md
    │   ├── .gitignore
    │   └── ...
    │
    └── ...
```

Each assignment has its own structure based on its technical requirements rather than following a fixed project template.

## Assignments

Assignments will be documented here as they are released and completed during the camp.

Each assignment directory contains:

* A dedicated `README.md` describing the problem, approach, implementation, and results.
* A project-specific `.gitignore`.
* Source code, notebooks, configuration files, tests, models, or other artifacts required by that particular assignment.

## Areas of Practice

Throughout the camp, the work in this repository may cover areas such as:

* Machine Learning
* Deep Learning
* Data Processing
* Model Development
* Model Evaluation
* APIs and Model Serving
* Containerization
* Data and Model Versioning
* Experiment Tracking
* MLOps
* Monitoring and Automation
* Production-oriented ML Engineering

The exact organization of assignments follows the work delivered during the program rather than a predefined weekly sequence.

## Repository Principles

The repository is maintained with a few core principles:

* Clear and consistent project organization
* Reproducible implementations whenever practical
* Assignment-specific environments and dependencies
* Meaningful Git history
* Clear technical documentation
* Separation of generated, temporary, and sensitive files from version-controlled source code
